# Truth Infrastructure for Step 3 Selection Gates

## Overview

The truth infrastructure provides a framework for validating selection results
against ground truth labels. It enables Step 3 of the Framework Selection
workflow by comparing claim verdicts from the science campaign against
expected truth values.

### Why It Exists

Selection gates require ground truth to distinguish between:
- **VERIFIED** - Selection matches truth (correct)
- **FALSIFIED** - Selection contradicts truth (error)
- **INCONCLUSIVE** - Selection lacks confidence (needs more evidence)
- **DANGER GAP** - Selection claims PASS when truth says FAIL (critical error)

### Key Components

| Component | Location | Purpose |
|-----------|----------|---------|
| Truth Schema | `experiments/truth/schema.py` | Versioned, hashable truth labels |
| Truth Generator | `experiments/truth/truth_generator.py` | Plugin-based label generation |
| Selection Schema | `experiments/selection/schema.py` | Selection result format |
| Verification Engine | `experiments/verification/verification_engine.py` | Compare truth vs selection |
| Step 3 Runner | `experiments/verification/run_step3.py` | CLI entry point |

### Gate Metrics

| Metric | Threshold | Description |
|--------|-----------|-------------|
| selection_truth | ≥ 0.95 | Accuracy over present claims |
| selection_danger_gap | = 0 | Zero false positives |
| selection_coverage | = 1.0 | All claims have selections |
| selection_confidence | ≥ 0.90 | High confidence rate |

## Architecture

### Data Flow

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  Truth Labels   │     │ Science Campaign │     │ Verification    │
│  (experiments/  │     │ Results          │     │ Engine          │
│  truth/)        │     │ (verdict.json)   │     │                 │
└────────┬────────┘     └────────┬─────────┘     └────────┬────────┘
         │                       │                        │
         │ TruthLabel            │ SelectionResult        │
         │ (expected truth)      │ (predicted verdict)    │
         │                       │                        │
         └───────────────────────┼────────────────────────┘
                                 │
                                 ▼
                    ┌────────────────────────┐
                    │  VerificationLedger    │
                    │  (ledger.jsonl)        │
                    │  - VERIFIED/FALSIFIED  │
                    │  - danger_gap flag     │
                    │  - match status        │
                    └───────────┬────────────┘
                                │
                                ▼
                    ┌────────────────────────┐
                    │  Gate Metrics          │
                    │  (step3_metrics.json)  │
                    │  - selection_truth     │
                    │  - selection_coverage  │
                    │  - selection_confidence│
                    └───────────┬────────────┘
                                │
                                ▼
                    ┌────────────────────────┐
                    │  Step 3 Verdict        │
                    │  (step3_verdict.json)  │
                    │  PASS or FAIL          │
                    └────────────────────────┘
```

### Plugin Architecture

Truth labels are generated by claim-specific plugins:

```
experiments/truth/plugins/
├── observer_claims.py    # W02-W20: Analytical truths
└── regression_claims.py  # claim2, claim3: Regression test truths
```

To add a new claim type:
1. Create plugin with `generate_truth(claim_id, root, **kwargs) -> TruthLabel`
2. Register in `TruthLabelGenerator.generate()` dispatch
3. Add claim ID to `docs/physics/claims.txt`

### Truth Types

| Type | Use Case | Example |
|------|----------|---------|
| boolean | Pass/fail claims | `{"should_pass": True}` |
| scalar | Numeric with tolerance | `{"d_s": 2.0}` with tolerance `{"d_s": 0.2}` |
| dict | Multiple values | `{"E0": -3.65, "S_ref": 0.48}` with per-key tolerance |

## Usage Guide

### Quick Start

```bash
# Generate truth labels
python -m experiments.truth.truth_generator --root . generate --claims docs/physics/claims.txt

# Validate truth labels
python -m experiments.truth.truth_generator --root . validate

# Run Step 3 verification
python -m experiments.verification.run_step3 \
    --claims docs/physics/claims.txt \
    --science-dir /path/to/run \
    --out /path/to/run/results/step3
```

### Makefile Targets

```bash
make step3-truth-generate   # Generate truth labels
make step3-truth-validate   # Validate truth labels
make step3-verify RUN_DIR=/path/to/run  # Run verification
```

### Adding a New Claim Type

1. **Create plugin**: `experiments/truth/plugins/my_claim.py`

```python
from pathlib import Path
from typing import Optional
from ..schema import TruthLabel

SCHEMA_VERSION = "truth.v1"

def generate_truth(claim_id: str, root: Path, substrate_id: Optional[str] = None, seed: Optional[int] = None) -> TruthLabel:
    return TruthLabel(
        schema_version=SCHEMA_VERSION,
        claim_id=claim_id,
        truth_type="boolean",
        expected={"should_pass": True},
        tolerance={},
        source="my_source",
        confidence=1.0,
        substrate_id=substrate_id,
        seed=seed,
    )
```

2. **Register in `truth_generator.py`**:

```python
if claim_id.startswith("MY"):
    from .plugins.my_claim import generate_truth
    return generate_truth(claim_id, self.root, substrate_id=substrate_id, seed=seed)
```

3. **Add claim ID to `docs/physics/claims.txt`**

### Adding a New Claim Pattern

If your claim uses a non-standard verdict file location, add a pattern to `ScienceVerdictSelectionEngine.CLAIM_PATTERNS`:

```python
CLAIM_PATTERNS = {
    "my_claim_id": ("my_claim_directory", "my_verdict_file.json"),
}
```

## API Reference

### TruthLabel

```python
@dataclass(frozen=True)
class TruthLabel:
    schema_version: str      # "truth.v1"
    claim_id: str            # "W02", "claim2_seed_perturbation"
    truth_type: TruthType    # "boolean" | "scalar" | "dict"
    expected: Any            # Expected value(s)
    tolerance: Any           # Tolerance for comparison
    source: str              # "analytical_theorem" | "regression_test"
    confidence: float        # 0.0 - 1.0
    substrate_id: Optional[str]
    seed: Optional[int]
    artifacts: Optional[Dict[str, TruthArtifactRef]]  # Heavy artifacts (SHA256)
    evidence_sha256: Optional[str]  # Integrity hash
```

### SelectionResult

```python
@dataclass(frozen=True)
class SelectionResult:
    schema_version: str      # "selection.v1"
    claim_id: str
    predicted: Dict[str, Any]  # {"verdict": "PASS", "should_pass": True, ...}
    confidence: float        # 0.0 - 1.0
    witness_path: Optional[str]  # Path to verdict.json
    substrate_id: Optional[str]
    seed: Optional[int]
```

### VerificationEngine

```python
class VerificationEngine:
    def __init__(self, high_conf_threshold: float = 0.9, low_conf_threshold: float = 0.5):
        ...

    def verify(
        self,
        truth_labels: Dict[str, TruthLabel],
        selections: Dict[str, SelectionResult]
    ) -> VerificationLedger:
        """Compare truth vs selection for all claims.

        Returns ledger with entries: VERIFIED | FALSIFIED | INCONCLUSIVE | MISSING
        """

    def compare(self, predicted: Dict[str, Any], truth: TruthLabel) -> Tuple[bool, str]:
        """Return (match, notes) for a single claim."""

    def check_danger_gap(self, predicted: Dict[str, Any], truth: TruthLabel) -> bool:
        """Return True if selection claims PASS when truth says FAIL."""
```

### step3_gate_metrics()

```python
def step3_gate_metrics(
    ledger: VerificationLedger,
    claim_ids: list[str],
    high_conf_threshold: float = 0.9
) -> Dict[str, Any]:
    """Calculate gate metrics from ledger.

    Returns:
        {
            "selection_truth": float,      # accuracy over present
            "selection_danger_gap": int,    # count of danger gaps
            "selection_coverage": float,    # fraction with selections
            "selection_confidence": float,  # high confidence rate
            "counts": {...}
        }
    """
```

### step3_gate_pass()

```python
def step3_gate_pass(
    metrics: Dict[str, Any],

    require_zero_danger: bool = True,
    require_full_coverage: bool = True,
    high_conf_threshold: float = 0.90
```

## Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| `MISSING` status | No verdict.json found | Check claim directory naming matches pattern |
| `FALSIFIED` status | Prediction contradicts truth | Investigate claim runner, check truth label |
| `danger_gap: true` | False positive detected | Critical - selection says PASS but truth says FAIL |
| Low confidence | High failure rate in metrics | Check `failures/samples` ratio in verdict.json |
| `KeyError: No truth plugin` | Unknown claim type | Add plugin or manual truth label JSON |
| Schema version mismatch | Outdated truth labels | Regenerate with `truth_generator validate` |

### Common Fixes

**Verdict file not found:**
```
Claim directory naming: claim_w02_poset_infimum/verdict.json
Add pattern to CLAIM_PATTERNS if non-standard.
```

**Truth label missing:**
```bash
# Generate missing label
python -m experiments.truth.truth_generator --root . generate --claim-id WXX

# Or create manually in experiments/truth/truth_labels/WXX.json
```

**Danger gap investigation:**
```json
// Check ledger entry for claim
{"claim_id": "WXX", "danger_gap": true, "predicted": {"verdict": "PASS"}, "truth": {"expected": {"should_pass": false}}}
// Selection incorrectly claims PASS when truth says FAIL
```

## Output Files

### ledger.jsonl

One JSON object per line, each entry:

```json
{
  "claim_id": "W02",
  "status": "VERIFIED",
  "match": true,
  "predicted": {"verdict": "PASS", "should_pass": true},
  "truth": {"truth_type": "boolean", "expected": {"should_pass": true}},
  "confidence": 1.0,
  "danger_gap": false,
  "witness": "/path/to/verdict.json"
}
```

### step3_metrics.json

```json
{
  "selection_truth": 0.95,
  "selection_danger_gap": 0,
  "selection_coverage": 1.0,
  "selection_confidence": 1.0,
  "counts": {"n": 20, "verified": 19, "falsified": 1, "missing": 0}
}
```

### step3_verdict.json

```json
{
  "step3_selection": "PASS",
  "reasons": {},
  "params": {"truth_threshold": 0.95, "high_conf_threshold": 0.9}
}
```
